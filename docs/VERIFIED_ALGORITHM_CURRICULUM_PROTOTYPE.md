# M2.6-d — verified algorithm curriculum prototype

Add four bounded stdin/stdout tasks: range sum queries (prefix/direct), interval union length (sort-merge/coverage), edit distance (matrix/rolling DP), unweighted graph distance (BFS/Floyd-Warshall). Each implementation has Japanese and English algorithm-specific instructions (16 records, 8 distinct sources). Inputs are 12 fixed/seeded development cases per family, including edge cases. Compile each exact in-tree reference with Java 17 and check exact stdout against Python reference calculations (96 comparisons). This is finite-case verification, not a mathematical correctness proof or independent assessment. Some oracle methods are similar to one Java variant; do not claim independent oracle authorship. No external or model-generated code is accepted by the harness; fixed commands and bounds are not a general sandbox. No model training, data adoption or heldout assignment. Rights review and overlap checks required before use. The new sources are development curriculum candidates, not hidden test tasks.
